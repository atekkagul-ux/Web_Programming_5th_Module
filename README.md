# 🚀 My Personal Portfolio Website

Welcome to my personal portfolio website repository! This project is built as part of my Web Development & Programming Internship journey (Module 05: Contact & Website Deployment).

## 📌 Features
- **Responsive Design:** Fully adaptable across mobile phones, tablets, and desktop computers.
- **Interactive Navigation:** Smooth scrolling and a mobile hamburger menu.
- **Dark/Light Mode:** Dynamic theme toggler with `localStorage` persistence.
- **Project Showcase:** Highlights milestones and completed modules (Modules 1 through 4) with direct GitHub repository links.
- **Resume Download:** Built-in downloadable resume support.
- **Interactive Contact Section:** Clean form layout with instant submission confirmation feedback.

## 🛠️ Technologies Used
- **HTML5** (Semantic structure)
- **CSS3** (Styling, Grids, Flexbox, and Dark Mode)
- **JavaScript** (Interactive theme toggling, mobile menu, and form validation)
